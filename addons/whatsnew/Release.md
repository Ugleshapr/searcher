# V8_SearchVar — улучшение поиска и добавление режимов

### Кратко

Добавлена поддержка поиска по базе данных РЖД. Для этого нажмите на "прайс-листу", режим переключится на поиск по "прайс-листу РЖД". Поддерживается горячая замена, можно проверять выдачу и так и так. Логика поиска в РЖД идентична той что в обычном режиме.
