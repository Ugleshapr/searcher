# V8_SearchVar — улучшение поиска и добавление режимов

### Кратко

Добавлена поддержка пометки товаров, **выведенных из ассортимента**, с использованием файла `keaz-old-products.csv`. Логика активируется **только при артикульном поиске**. В выдаче таким позициям вместо цены отображается **«Выведен»** с красной плашкой.

---

### Что изменено

**Frontend / UI**

* Новая визуальная метка: `.price-tag.is-withdrawn` — красная плашка для выведенных позиций.
* В таблице результатов в колонке цены у «выведенных» отображается текст **«Выведен»** и тултип **«Выведен из ассортимента»**.

**Поисковая логика**

* При запросах по артикулу (один артикул или список артикулов, длина токенов по 6 цифр) приложение:

  * лениво подгружает `keaz-old-products.csv` из корня;
  * строит множество артикулов, выведенных из ассортимента;
  * помечает результирующие позиции флагом `__withdrawn`.
* При **текстовом поиске** файл не грузится, флаг не используется.

---

### Поведение после обновления

* **Текстовый запрос**: логика прежняя; запросы к `keaz-old-products.csv` **не выполняются**; плашек «Выведен» нет.
* **Один артикул (6 цифр) или список артикулов**: загружается `keaz-old-products.csv` (один раз на сессию); совпавшие позиции помечаются «Выведен» красной плашкой, цена не показывается.
* Сортировки/фильтры/подсветка совпадений — без изменений.
